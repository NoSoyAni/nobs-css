## ⚡ Descripción General

**NOBS** es un tema personalizado completo. Diseñado con un enfoque futurista tipo HUD táctico/ciberpunk, ofrece una interfaz limpia, estilizada y moderna sin alterar el rendimiento ni la funcionalidad original de la web.

El código se encuentra **finalizado y 100% funcional**, aunque actualmente está marcado como versión **BETA** para recibir feedback y corregir posibles detalles visuales menores.

---

## 🚀 Instalación

Para instalar **NOBS** directamente en la plataforma:

1. Ve a los **Ajustes / Configuración de usuario**.
2. Busca el apartado dedicado a la **URL del CSS personalizado** (Custom CSS).
3. Pega el enlace alojado en GitHub Pages:

```text
https://TU-USUARIO.github.io/NOBS/nobs.css
```

4. Guarda los cambios para aplicar la nueva interfaz inmediatamente.

## 🐛 Reporte de Bugs y Errores

Dado que el proyecto se encuentra en **fase BETA**, si encuentras algún fallo visual, desalineación o elemento no estilizado:

1. Dirígete a la pestaña de [**GitHub Issues**](../../issues) en este repositorio.
2. Abre una nueva entrada (*New Issue*).
3. Adjunta una captura de pantalla del problema junto con el navegador y resolución que estás utilizando.
